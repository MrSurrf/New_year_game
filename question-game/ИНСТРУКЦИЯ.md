# Инструкция: как заменить контент игры на свой

Весь контент игры (вопросы, персонажи, звуки, картинки, настройки) лежит в файлах,
которые можно редактировать обычным текстовым редактором или простой подменой файлов.
Код трогать не нужно. После изменения файлов просто перезапустите игру (F5 в редакторе).

**Важно:** имена файлов и структуру папок менять нельзя — игра ищет файлы по этим путям.
Если добавляете новый файл, сохраняйте указанный формат (JSON / PNG / WAV).

---

## 1. Настройки игры — `data/config.json`

```json
{
  "answer_time_sec": 30,        // секунд на ответ игрока
  "steal_time_sec": 10,         // секунд на перехват второй командой
  "points_correct": 2,          // очки за правильный ответ
  "points_steal": 1,            // очки за правильный перехват
  "questions_first_pick": 3     // сколько вопросов задаётся при первом выборе категории
}
```

## 2. Вопросы и категории — `data/categories.json`

Список категорий. Сколько категорий в файле — столько плиток на экране категорий.
**В каждой категории должно быть ровно 6 вопросов.**

Два типа вопросов:

```json
{
  "id": "history",
  "name": "История",
  "questions": [
    {
      "id": "h1",
      "type": "open",
      "text": "В каком году началась Первая мировая война?",
      "answer": "1914",
      "hint": "Сараево"
    },
    {
      "id": "h2",
      "type": "choice",
      "text": "Кто был первым президентом США?",
      "options": ["Линкольн", "Вашингтон", "Джефферсон", "Адамс"],
      "answer": "Вашингтон"
    }
  ]
}
```

- `type: "open"` — игрок отвечает устно, ведущий судит. Поля: `text`, `answer`
  (показывается ведущему), `hint` (необязательно; показывается способностью «Подсказка»).
- `type: "choice"` — на экране появляются варианты. Поля: `text`, `options`
  (2–6 вариантов), `answer` — должен **точно совпадать** с одним из вариантов.
- `id` вопросов и категорий должны быть уникальными, без пробелов (латиница, цифры, `_`).

## 3. Персонажи и способности — `data/characters.json`

```json
{
  "id": "mage",
  "name": "Маг",
  "ability": {
    "name": "Рискованная магия",
    "description": "+5 очков, но команда пропускает следующий раунд",
    "effects": [
      { "type": "add_points", "value": 5 },
      { "type": "skip_next_round" }
    ]
  }
}
```

Доступные эффекты (можно комбинировать несколько в одной способности):

| type | Параметры | Что делает |
|---|---|---|
| `add_points` | `value` (можно отрицательный) | Даёт/снимает очки отвечающей команде |
| `skip_next_round` | — | Отвечающая команда пропускает следующий раунд |
| `show_hint` | — | Показывает `hint` текущего вопроса |
| `extra_time` | `value` (секунды) | Добавляет время к таймеру |
| `double_points` | — | Удваивает очки за текущий вопрос |

Способность активируется кнопкой ведущего, один раз за раунд.
`id` персонажа должен совпадать с именем его папки с картинками (см. ниже).

## 4. Картинки персонажей — `assets/characters/<id>/`

Для каждого персонажа папка с его `id` из `characters.json`, внутри два файла:

- `frame1.png` — первый кадр
- `frame2.png` — второй кадр

Вместе они образуют короткую анимацию при выборе персонажа в ростере.
Замените заглушки своими PNG с теми же именами. Рекомендуемый размер — 128×128
или больше (квадрат). Новый персонаж = новая папка + запись в `characters.json`.

## 5. Звуки — `sound/`

Заменяйте файлы своими, сохраняя имена. Формат любой из: **WAV, OGG или MP3** —
игра сама найдёт файл с нужным именем и любым из этих расширений. Держите в папке
только один файл с каждым именем (иначе приоритет: WAV → OGG → MP3).

| Файл (имя без расширения) | Когда играет |
|---|---|
| `sound/music/background_loop` | Фоновая музыка, играет весь матч по кругу |
| `sound/ui/click` | Нажатие любой кнопки |
| `sound/ui/switch` | Переключение между экранами |
| `sound/choise/correct` | Ведущий нажал «Верно» |
| `sound/choise/wrong` | Ведущий нажал «Неверно» |
| `sound/abilities/` (все файлы в папке) | Активация способности — играет **случайный** звук из папки |
| `sound/game_start/game_start` | Нажатие «Начать игру» на стартовом экране |
| `sound/character_select/character_select` | Выбор персонажа в ростере |
| `sound/category_select/category_select` | Выбор плитки категории |
| `sound/steal/steal` | Начало перехвата (вопрос уходит другой команде) |
| `sound/timer/timer_tick` | Тиканье последних 5 секунд таймера |
| `sound/timer/timeout` | Время вышло |
| `sound/round_end/round_end` | Окончание раунда (кроме последнего) |
| `sound/game_end/game_end` | Финал: показ экрана результата |

В папку `sound/abilities/` можно класть сколько угодно файлов (`ability_1.mp3`,
`ability_2.mp3`, `fanfare.wav`, …) — при каждой способности выбирается случайный.

Сейчас там простые тоновые заглушки, сгенерированные скриптом
`tools/generate_media_placeholders.py` (можно перегенерировать: `python tools/generate_media_placeholders.py`).

## 6. Фон и оформление — `assets/`

- `assets/backgrounds/back/` — **анимированный фон стартового экрана**: секвенция
  кадров PNG (сейчас 52 кадра 864×496). Кадры проигрываются по кругу со скоростью
  12 кадров/с (меняется параметром `fps` в `scripts/animated_background.gd`).
  Чтобы заменить анимацию: удалите старые кадры и положите свои PNG — количество
  кадров любое, играют в алфавитном порядке имён (нумеруйте с ведущими нулями:
  `frame_001.png`, `frame_002.png`, …).
- `assets/backgrounds/main_background.png` — **статичный фон экрана выбора
  персонажа и экрана вопросов**. Замените своим PNG с тем же именем
  (заглушка — градиент 1280×720; можно любого размера, растянется).
- `assets/ui/` — папка для прочего оформления (рамки, панели, логотипы).
  Сейчас пустая: файлы отсюда не подключены автоматически — когда будете готовы,
  скажите, какие элементы куда поставить, и я подключу их в сцены.

## Частые ошибки

- **Игра пишет ошибку в консоли про JSON** — проверьте запятые и кавычки, JSON не прощает
  лишних запятых. Удобно проверить файл на любом JSON-валидаторе онлайн.
- **Категория не появляется / игра ругается** — в категории должно быть ровно 6 вопросов.
- **Персонаж без картинки** — папка `assets/characters/<id>/` не совпадает с `id`
  или в ней нет `frame1.png` / `frame2.png`.
- **Звук не играет** — имя файла не совпадает (смотрите таблицу выше) или расширение
  не WAV/OGG/MP3. Также проверьте, что рядом не лежит старый файл с тем же именем,
  но другим расширением — игра возьмёт только один по приоритету WAV → OGG → MP3.
- **Кириллица превратилась в кракозябры** — сохраняйте JSON в кодировке UTF-8
  (в «Блокноте»: «Сохранить как» → кодировка UTF-8).

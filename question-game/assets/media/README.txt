Сюда складывайте медиафайлы для вопросов.

Структура (рекомендуемая, можно свою):
  assets/media/films/       — кадры из фильмов (.png, .jpg, .webp)
  assets/media/soundtracks/ — отрывки саундтреков (.ogg, .wav, .mp3)

После копирования файла сюда откройте проект в редакторе Godot,
чтобы он импортировал файл (создаст .import рядом), иначе игра его не увидит.

Как привязать файл к вопросу — см. data/media_questions_example.json
